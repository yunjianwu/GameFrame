# 流场寻路 Flow Field —— Unity 版

对应文章：《A* 算到 CPU 冒烟？用“流场寻路”让同屏万怪满帧丝滑冲锋！》（https://mp.weixin.qq.com/s/dWipYjhhBvSYJyy_WaFe5Q）
浏览器版：`../../demos/flow-field-pathfinding/`

## Unity 版本

- 目标：Unity 2022.3 LTS 与 Unity 6（6000.0）。
- 渲染：动态 Mesh + `Graphics.DrawMesh` + `Sprites/Default`，Built-in / URP 通用；UI 与积分场数字用 IMGUI。
- 输入：自动适配旧 Input Manager / 新 Input System。

## 打开与运行

**方式 A：直接把本目录当工程打开**
Unity Hub → Add project from disk → 选 `flow-field-pathfinding/`。打开后在默认场景里直接按 Play。

**方式 B：拷进已有工程**
把 `Assets/FlowFieldPathfinding/` 拷进任意工程的 `Assets/`，打开任意场景按 Play。

不需要搭场景：`FlowFieldBootstrap` 会自动创建 `FlowFieldDemo`。建议一个 Demo 一个工程。

## 操作

右侧面板：

| 控件 | 效果 |
| --- | --- |
| 第一步 代价场 | 深灰 = 墙（255），蓝紫 = 沼泽（5），其余平地（1），绿色圆 = 终点 |
| 第二步 积分场 | 青色热力图 + 每格到终点的累计代价数字；沼泽里的数字会明显跳涨 |
| 第三步 向量场 | 每格一根金色箭头；墙角处不会斜刺进墙 |
| 第四步 查表狂奔 | 每 2 秒随机出生一只，抵达终点即消失；“一次放出 300 只”可看到全挤成一条线的问题 |
| 第五步 尸潮推挤 | 叠加九宫格同伴排斥；“同屏数量”滑条 100～10000，从最左侧出发；抵达核心的怪被吸收、在左侧补充，核心发出脉冲波；沼泽里的怪显示为蓝色 |
| 画墙 / 沼泽 / 擦除 | 选择画笔 |
| A* 对照 | 让当前每只怪（不足 5000 时补足 5000 个随机起点）各跑一次 A*，与重建一次流场的耗时对比，结果显示在面板里 |
| 重置地图 | 恢复默认迷宫 |

鼠标：**左键拖动**用当前画笔涂格子，**右键**把终点移到该格。地图一改，流场立即重算，箭头和怪群同步改道。HUD 显示怪物数量、FPS、流场重建耗时、怪物逻辑耗时。

## 代码结构

| 文件 | 说明 |
| --- | --- |
| `Scripts/FlowField.cs` | 第一～三步：代价场 / 积分场（标号修正式扩散）/ 向量场（防斜穿墙角）。**纯 C#，不引用 UnityEngine** |
| `Scripts/Crowd.cs` | 第四～五步：O(1) 查表移动、沼泽减速 0.45、X/Y 分轴贴墙滑动、九宫格分桶推挤（纯 C#） |
| `Scripts/AStar.cs` | 对照组 A*：二叉堆、八方向距离启发，边权和防切角规则与流场一致（纯 C#） |
| `Scripts/FlowMap.cs` | 默认 48×27 迷宫，与浏览器版完全相同 |
| `Scripts/FlowFieldDemo.cs` | MonoBehaviour：输入、绘制、IMGUI 面板、A* 对照按钮 |
| `Scripts/FlowFieldBootstrap.cs`、`Scripts/Common/` | 自动创建、相机、批绘制、输入适配、IMGUI 工具 |
| `DotnetChecks/` | 编辑器外的编译检查、逻辑测试与压测 |

说明：
- 地图坐标与原文一致：`[x, y]`，y = 0 为最上面一行；绘制时再换算成 Unity 的 Y 向上世界坐标。
- 新画的墙正好压住怪物时，该怪物会被移除（文章没提这种情况，这是本 Demo 的处理方式，与浏览器版相同）。
- 到达不了终点的格子积分为 `Infinity`、向量为零，站在那里的怪原地不动。

## 性能说明

.NET 8 Release 下纯逻辑（48×27 迷宫，5000 只怪）：

| 项目 | 耗时 |
| --- | --- |
| A*：5000 次独立搜索 | 约 345 ms（平均每次展开 317 个节点） |
| 流场：重建一次积分场 + 向量场 | 约 0.12 ms（与怪物数量无关） |
| 流场：5000 只查表移动 + 九宫格推挤 | 约 2.0 ms/帧 |

即“全体重新寻路”这一步差约 2800 倍；浏览器版测得约 1000 倍，结论一致。编辑器 Mono JIT 下数字会大一些。1 万只时渲染是一张约 7 万顶点的动态 Mesh，CPU 端重建 Mesh 也有开销，可在 Profiler 里观察。

## 已验证 / 未验证

在 Linux 虚拟机上实际执行了 `DotnetChecks/run-checks.sh`：

- **编译**：对 Unity 6000.0.85f2 与 2022.3.62f3 编辑器自带的真实 `UnityEngine.*Module.dll` 编译全部脚本，旧输入 / 新输入系统（桩）两种配置均 0 警告 0 错误。

  - 文章 3×5 小例子：从 (0,1) 沿 `(1,2)→(2,2)→(3,2)→(4,2)→(4,1)` 绕开沼泽到达终点；

  - 封住左侧城墙上方缺口后，(11,5) 的箭头从 ↘ 变为 ↓，(5,5) 的积分 55.3 → 66.1；
  - 2000 只带推挤从最左侧出发，60 秒内全部到达；
  - 上表压测。
